A browser tab as a node (X1)

Open this page as A and as B in two tabs. They find each other on this device, connect over a real WebRTC data channel through falllink, the estate's connection layer, and each runs a foundation node. A sends ten signed LIGHT packets to B, then one with a byte changed and one sent twice. B's own door decides each. No STUN server is used, so nothing leaves the machine. Back to Phase 3.
